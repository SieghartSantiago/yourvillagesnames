# Your Villages Name Mod

This mod is for Minecraft **1.21.1** using **NeoForge**.

If you find any issues or have a feature request for the mod, please let me know in the Issues section.

For now, the mod includes the following languages: **en_us**, **es_ar**, **es_es**, **es_mx**, **es_ve**, **es_cl**, **es_ec**, and **es_uy**.
If you want to contribute a translation, please let me know in the Discussions section, under the Translation category.
